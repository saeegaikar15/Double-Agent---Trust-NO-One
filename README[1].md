# DOUBLE AGENT — Trust NO One

A dark, competitive espionage game about secret objectives, bluffing, intel, and accusations.

## Features
- Choose between an AI opponent and pass-and-play on one device.
- Secret missions with different objectives.
- Four actions: Trust, Investigate, Sabotage, and Deceive.
- Intel, heat, mission progress, intercepted clues, and an operation log.
- Accusations that can expose an opponent or penalise a wrong guess.
- Responsive interface for desktop and mobile screens.

## How to Play
1. Open the game and choose **Against the machine** or **Pass & play**.
2. Read your classified mission.
3. Select one action and commit it.
4. Use intel and clues to infer the other agent's mission.
5. Reach 3 progress to complete your mission, or expose the opposing agent with a correct accusation.
6. Keep your heat under control; too much heat can get your cover blown.

## Files
- `index.html` — page structure and game interface.
- `style.css` — visual styling and responsive layout.
- `script.js` — game rules, actions, AI behaviour, and interface interactions.

## Run Locally
Keep all three files in the same folder, then open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your GitHub repository.
2. Commit the files to your publishing branch (usually `main`).
3. In **Settings → Pages**, select the correct branch and `/ (root)` if asked.
4. Open the published URL shown in GitHub Pages.

## Important Note
The AI mode and pass-and-play mode run in the browser. This version does **not** provide real-time online multiplayer between separate devices, and game state is not stored on a server.
